# 效果证据与使用边界

[English](EVALUATION.md) · [成果展示](showcase/README_zh.md) · [开始使用](USAGE_zh.md)

SimpleAutoResearch 适合公开试用，不是生产可靠性承诺。优先从已有数据分析、Python 代码工作、图文反馈和材料报告开始；开放调研与自主复现仍需要更多审阅。项目许可证尚未确定，目前为源码可见预览。

## 能重建，不等于能无人干预生成

公开案例有三种不同含义：

- **直接阅读：** 打开已生成 PDF、图和正文，不需要模型。
- **离线复跑：** 使用保存数据与已生成源码重新计算、绘图或编译，不重复调查和模型生成。
- **新模型任务：** 按教程发送新目标、材料和权限，产生新费用；产物、时间和成功率都可能不同。

人参与了目标说明、审批、缺陷反馈、环境依赖和独立检查，没有代写这些案例的科学正文或图形代码。开发过程中修改过框架，也有显式续接。原生 `partial` 未改成成功；保存结果分析和机器人调研分别累计 180/164 次已结算物理请求、5,871,880/6,086,900 个已结算 tokens，未知用量另留。它们**不能作为单次普通用户任务的效率证据**。

## 使用时仍需留意

- **长任务和成本：** 重复调查、协调开销与人工干预尚未稳定收敛。先做范围有限的任务，审阅初稿再扩展；不要照开发案例的累计成本预付或承诺额度。
- **API 与网络：** 服务和执行主机都会影响调用。最终报告使用官方 DeepSeek；CCTQ 直连长流不稳定未被认证为彻底解决，不保证换个端点就恢复。
- **证据与出版：** 已取得全文不代表正确采用；引用与论断仍要查原文。PDF 编译不等于论文质量或会议模板合规。
- **安全边界：** 来源原件只读不等于 OS 沙箱。审阅执行命令，只编译可信 TeX，不上传凭据和无关私有材料。可信本地 Python 扩展拥有宿主进程的操作系统权限，只读／计划声明不构成 Python 沙箱。
- **界面范围：** 浏览器客户端为单用户本机实验界面，不是多用户服务；首次使用以 CLI 教程为准。

## Benchmark 与发布状态

已有 [ARC-Bench](../benchmark/arc_bench/README_zh.md) 和 [SurveyBench](../benchmark/survey_bench/README_zh.md) 适配器，**没有当前版本的官方成绩或可据以比较的总体成功率**，也不宣称 PaperBench、ScienceAgentBench 成绩。接口检查和选取的开发案例不能替代固定预算、隐藏评价材料与独立评价器的正式测试。

当前开发批次不新增官方 benchmark 成绩，不修改许可证，不发布正式 Release。公开试用的承诺是：提供真实输入、明确命令、可检查成果和诚实限制，而不是保证每个科研问题自动解决。
