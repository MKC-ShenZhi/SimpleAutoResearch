# 效果证据与使用边界

[English](EVALUATION.md) · [成果展示](showcase/README_zh.md) · [开始使用](USAGE_zh.md)

SimpleAutoResearch 适合公开试用，不是生产可靠性承诺。优先从已有数据分析、Python 代码工作、图文反馈和材料报告开始；开放调研与自主复现仍需要更多审阅。项目许可证尚未确定，目前为源码可见预览。

## 哪些能力有实际证据

| 能力 | 已核实的成果 | 不能据此承诺 |
| --- | --- | --- |
| 数据分析与图文反馈 | 保存结果生成五面板图、四表、六页 PDF；72 项独立数值核查，搬迁复跑 | 任意统计设计正确、无需反馈或低成本完成 |
| 方向调研与写作 | VLA/世界模型十页报告、16 项引用、两图两表；逐页查看、搬迁编译 | 穷尽检索、充分采用所有全文或完整作者元数据 |
| 已有结果改图 | 八个显示值与冻结数据核对，同环境搬迁 PNG 一致 | 新实验、外部站点泛化或印刷质量 |
| Python 代码创建与修改 | 已有 FASTA 创建/反馈、异常输入和搬迁，以及工程补丁验证 | 任意语言或大型仓库自主开发 |
| 有限复现 | 已有 CQR 调查、准备、短跑、缩减测量、报告与搬迁 | 完整论文、任意新机器或等价原后端复现 |
| 历史继续与记录 | 原身份、权限、失败、未知用量和账本保留 | 自动重试未知请求或无上限后台运行 |

[展示页](showcase/README_zh.md)提供可读 PDF、源码入口、成本和限制。较早成果保留原版本；两份新报告最终使用与 `d3b0721` 等价的代码，完整任务过程跨候选。公开文件的逐字节对应关系见各案例的 `provenance.json`。

## 能重建，不等于能无人干预生成

公开案例有三种不同含义：

- **直接阅读：** 打开已生成 PDF、图和正文，不需要模型。
- **离线复跑：** 使用保存数据与已生成源码重新计算、绘图或编译，不重复调查和模型生成。
- **新模型任务：** 按教程发送新目标、材料和权限，产生新费用；产物、时间和成功率都可能不同。

人参与了目标说明、审批、缺陷反馈、环境依赖和独立检查，没有代写新案例的科学正文或图形代码。开发过程中修改过框架，也有显式续接。原生 `partial` 未改成成功；两份新报告分别累计 180/164 次已结算物理请求、5,871,880/6,086,900 个已结算 tokens，未知用量另留。它们**不能作为单次普通用户任务的效率证据**。

## 工程核查

本次合入前，Linux 离线回归发现 2,119 项：2,113 通过、6 项条件性跳过；安装包另通过 7 项关键行为检查。277 份打包文件与源码/模板一致，102 条教程命令通过实际解析。缺少 Node 而跳过的接收方渲染检查另在本机 Node 上通过。

公开图表源码、六页分析报告和十页调研报告均按教程在新目录复跑/重建；冻结输入未改，派生数值文件一致。检查没有重新调用付费模型，也不把离线复跑冒称新生成任务成功。原任务的交付哈希、失败与账本仍保留。

这些检查覆盖合同和软件行为，不是科研任务成功率，也不证明全部平台、所有依赖环境或九万行实现已审计干净。产品和测试近期仍有净增，不能宣称整体瘦身已完成。

## 使用时仍需留意

- **长任务和成本：** 重复调查、协调开销与人工干预尚未稳定收敛。先做范围有限的任务，审阅初稿再扩展；不要照开发案例的累计成本预付或承诺额度。
- **API 与网络：** 服务和执行主机都会影响调用。最终报告使用官方 DeepSeek；CCTQ 直连长流不稳定未被认证为彻底解决，不保证换个端点就恢复。
- **证据与出版：** 已取得全文不代表正确采用；引用与论断仍要查原文。PDF 编译不等于论文质量或会议模板合规。
- **安全边界：** 来源原件只读不等于 OS 沙箱。审阅执行命令，只编译可信 TeX，不上传凭据和无关私有材料。
- **界面范围：** 浏览器客户端为单用户本机实验界面，不是多用户服务；首次使用以 CLI 教程为准。

## Benchmark 与发布状态

已有 [ARC-Bench](../benchmark/arc_bench/README_zh.md) 和 [SurveyBench](../benchmark/survey_bench/README_zh.md) 适配器，**没有当前版本的官方成绩或可据以比较的总体成功率**，也不宣称 PaperBench、ScienceAgentBench 成绩。接口检查和选取的开发案例不能替代固定预算、隐藏评价材料与独立评价器的正式测试。

本次不新增大评测，不修改许可证，不发布正式 Release。公开试用的承诺是：提供真实输入、明确命令、可检查成果和诚实限制，而不是保证每个科研问题自动解决。
