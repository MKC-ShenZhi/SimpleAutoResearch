## 实际展示了什么

| 案例 | 保存结果及核查 | 必须保留的限定 |
| --- | --- | --- |
| 方向调查 | 从问题而非论文清单出发，按 CPU/离线新条件修改建议，交付报告/TeX/PDF | 有界开发案例，不是穷尽式 DeepResearch；另一个失败调研不计成功 |
| Bike Sharing 分析报告 | 六面板修订图、四页 PDF；732 数值格独立复算，零差异 | 观察性分析；跨候选且有续额，不是同版本单额度成功 |
| 保存结果改图 | 核对 8 个显示值、五份数据不变；实际看图、当前请求交付及搬迁 PNG 字节相同 | 当前 `f45b596` 案例，原生限定 `partial` 保留；未重拟合或科学再验证 |
| 代码创建/维护 | FASTA 从零创建、gzip/过滤反馈、独立正常/异常行为与搬迁；另有 CQR 工程补丁重建和运行 | 支持范围为 Python，不覆盖任意语言或未运行的历史 scikit-garden 后端 |
| 有限 CQR 复现 | 仅给论文及资源，随后调查实现/数据/依赖、准备短跑、五种子测量、分析报告及搬迁 | 单数据集、缩减设置和替代后端，不是全论文或全新机器复现 |
| 结果复用/实质修订 | 保留原测量，修改论证和图形，原件与费用不变 | 较早报告需要调用方确认限定交付，不是通用无人干预成功 |

这是选取的开发验收，不是随机样本。人参与任务说明、副作用批准、框架修复和独立核查，**不能据此计算总体成功率或宣称优于其他 Agent**。

公开报告、图片和哈希见[展示页](showcase/README_zh.md)；小型[改图成果含源码/数据，可从仓库复跑](../examples/figure-feedback/README_zh.md)。完整开发运行归档和凭据不随仓库发布。

## 成本不能从展示中消失

| 案例 | 物理模型请求 | 记录 tokens | 其他成本与限定 |
| --- | ---: | ---: | --- |
| Bike Sharing | 63 | 已结算 2027970 | 含出版共 40 进程；另保留五笔共 127644 tokens 未知预留；原额度有扩展 |
| 最新有界改图 | 11 | 211774 | 一次任务渲染约 2.56 秒，本任务无 unknown/续额；更早失败任务及其 21638 未知预留另存 |
| 有限 CQR 复现及交付 | 96 | 3233239 | 59 进程，另保留 344690 tokens 未知上界；不是时延/吞吐 benchmark |

tokens 不等于金额，渲染进程时长不等于任务总耗时。开发时的模型、提供方和重试设置不同，不推导免费用量、实际价格或同预算优势。

## 工程检查

固定安装发现 2041 项：2037 通过、4 跳过；其中三项可选导出/重建另在同安装显式通过，Linux 未执行 Windows Job Object 检查。十组历史继续及三个停止合同载入保持身份和账本。10 月 18 日另补查八个既有配置/续接/复用/审批/恢复场景，全通过，无真实模型调用。

这些不是 2041 项科研任务或 benchmark 成功率。最新改图另有真实模型/vision/渲染/交付证据；旧案例仍属原候选，不能称六类全部在当前版重跑。

## 外部 benchmark 状态

已有 [ARC-Bench](../benchmark/arc_bench/README_zh.md) 和 [SurveyBench](../benchmark/survey_bench/README_zh.md) 适配器。接口、历史诊断或格式通过，不等于当前 V2.9 官方成绩。ARC 历史默认会给生成端可读 rubric，不可与隐藏 rubric 的系统无说明比较。目前不宣称 PaperBench 或 ScienceAgentBench 成绩。

后续正式比较须固定框架/模型/工具版本、任务划分与访问方式、相同预算、隐藏评估材料、实际评价器、费用/失败/未知用量及人工介入。本轮不启动新的大评测。

## 剩余限制与发布边界

- 网络依赖部署环境：成功改图用过临时受限 TLS 中继；后来匿名直连返回预期 401，仅证明当时可达，不认证模型调用或长流稳定。
- 搬迁使用已有固定环境，不认证任意新机、GPU 或平台。
- 深调研、长文论证、出版观感与完成效率仍不均衡。
- 已退出已知旧 CLI 新建控制，但兼容 API 仍保留；维护债未审净，最近收尾代码/测试是净增而非整体瘦身。
- 工作区不是 OS 沙箱；审阅命令、保护凭据，unknown 不被悄悄重放或清空。
- 许可证和正式 tag/GitHub Release 另作决定。不得把案例称为官方 benchmark 成绩或自主科学发现。
