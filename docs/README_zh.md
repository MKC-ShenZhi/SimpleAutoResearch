# 文档导航

[English](README.md) · [项目介绍](../README_zh.md)

第一次使用从入门教程开始。按自己的目标发起任务，需要时再查询命令或配置；
不需要先学习所有工具，也不必按六类能力逐项运行。

## 开始使用

- [入门教程](USAGE_zh.md)：安装、模型配置、提供材料、查看成果和继续任务。
- [成果展示](showcase/README_zh.md)：完整报告、图形、源码、复跑方法及运行条件。

## 完成日常任务

[任务指南](WORKFLOWS_zh.md)按研究需求组织：方向调研、代码工作、数据分析、绘图、
材料写作和有限复现。已有结果可以继续使用，PDF 按需导出。

## 按需查阅

- [命令参考](CLI_REFERENCE_zh.md)：查一个命令的用途、参数和使用示例，包括继续任务与独立工具。
- [配置参考](CONFIG_REFERENCE_zh.md)：查凭据、模型和任务配置放在哪里，字段含义、默认值及修改何时生效。
- [更新记录](../CHANGELOG_zh.md)：按日期查看用户可感知的变化。

## 参与开发

[开发指南](DEVELOPMENT_zh.md)介绍架构、代码归属、修改与验证方式。
贡献者需要这些实现信息；普通使用无需阅读。

当前为源码可见预览，许可证尚未确定。案例中的人工参与、成本与限制见
[展示说明](showcase/README_zh.md#人工参与版本和成本)；模型任务会产生服务商费用，
既有图表的离线复跑不等于重新生成一次研究成果。
