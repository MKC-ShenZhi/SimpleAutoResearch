# Local note inspection

Use local_notes__count_words for a small note in the current task's mounted
sources. Read the returned coverage and original text with read_file when
needed. A bounded word count is an observation, not a scientific conclusion.
Combine it with the existing host tools to answer the user's request. Cite
the actual mounted source; disclose truncation or inaccessible files. Ask the
user for missing material with ask_user. These instructions grant no access,
process, network, publication or write permission.
