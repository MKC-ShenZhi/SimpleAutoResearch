# 中文简报：VLA 策略与世界模型，该怎么选

**面向对象**：刚进入机器人学习的课题组；没有大规模真机集群。

## 1. 核心结论

- "VLA vs. 世界模型"不是同一层级的对比。VLA 学的是 `观测 (+语言) → 动作`；世界模型学的是 `观测 + 动作 → 未来`。后者至少有三类用法：测试时规划/优化动作、生成合成训练数据、把策略放进模型里训练。三者共享建模技术，但数据、失效模式与评估方式完全不同，不能当成一个"家族"统一打分。
- 选型前先问"我的瓶颈在哪"：**没有本体数据** → 先看世界模型做数据增广与预训练（DreamGen、Cosmos 一类）；**有演示但闭环精度不够** → 先看动作表示与推理时延（π0、OpenVLA、GR00T N1）；**要做长程任务分解** → 看带显式推理的 VLA（Gemini Robotics 1.5）。
- **视频好看 ≠ 控制成功**。像素级视频预测的视觉保真度与其作为控制器/评估器的可用性之间没有已被证明的等价关系；请以闭环成功率、真机盲评（RoboArena、LBM 式研究）为准。

## 2. 哪些数字能比、哪些不能

- **可比**：同一 benchmark（如 LIBERO）、同一任务集/初始状态分布、同一评测脚本、同一动作空间与观测定义下的成功率。
- **不可比**：不同论文自建任务集上的成功率；仿真与真机混排；不同训练数据量（几万到上亿帧）下的"零样本泛化"；用不同 VLM 骨干与不同动作 chunk 长度的推理时延。
- 报告数字时必须带上条件：数据集规模与来源、本体、动作频率、是否使用 proprio、评测 episode 数。

## 3. 本报告的覆盖范围（请注意）

- 语料为 **16 篇唯一论文**（覆盖程度不一致：个别条目只用元数据或摘要级表述；2026 年的 PlayWorld 已取得较完整的 HTML 全文并保留在证据包中，但正文只用了其摘要级表述，因此没有论断依赖其全文），另外若干条仅有元数据记录；**不是** 2025–2026 的全面综述。
- 2026 年只覆盖 **2 篇**，且其中一篇（PlayWorld）只用了摘要级表述，因此近期覆盖很窄，不能据此外推"领域现状"。
- 文中所有性能数字均标注来源与条件；矩阵中的"—"表示**本次检索语料中未找到**，不代表该能力在文献中不存在。

## 4. 下一步可行的低成本研究（无需机队）

1. 在 LIBERO / SimplerEnv 上复现 2–3 个开源策略（OpenVLA、π0、SmolVLA）的**同一协议**评测，报告推理时延与成功率。
2. 用已开源的世界模型（DINO-WM、V-JEPA 2）在仿真中做规划，量化"预测误差 → 下游成功率"的传递。
3. 小规模真机（单臂 + 桌面）做**数据增广消融**：同一策略，真实数据 vs 真实+世界模型合成数据。
4. 建立内部评测规范：固定 episode 数、随机种子、初始状态分布，公开失败视频。
